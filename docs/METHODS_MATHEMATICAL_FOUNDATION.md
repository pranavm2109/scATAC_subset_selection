# Mathematical and implementation specification for manuscript Methods

Prepared from the current project code, 2026-10-25. This is a source-linked specification for drafting Methods, not a new analysis or a claim of methodological novelty. Keep algorithm definitions, evaluation definitions and observed results separate. Use the supplied scSampler Methods only as a structural reference: do not transfer its algorithm, assumptions, performance claims or wording into this manuscript.

## 1. Notation and study design

For each atlas independently, let V={1,...,N} index cells and p={1,...,P} index retained peaks. Let C_ip be the original nonnegative peak count, b_ip=1[C_ip>0] its binary detection indicator, and y_i the supplied cell-type annotation. Annotations are not supplied to PeakVI as labels, landmark fitting or subset selection. They are used afterward for evaluation and one-versus-rest DA.

Budgets are f in {0.02,0.04,0.06,0.08,0.10}, with k_f=max(1,round(N f)) using Python's rounding. Every budget is fitted independently with seed 123; memberships are not generated by truncating one largest-budget selection. Atlases are trained and selected separately; there is no joint atlas integration in these rules.

Sources: [Snakefile](../workflow/Snakefile), [selection script](../scripts/03_subset_selection_on_peakvi.py), [PeakVI wrapper](../scripts/02_3_run_peakvi.py).

## 2. Input preparation and peak universe

Counts and existing annotations come from the supplied atlas files. Kidney loads the GSE211785 count RDS and metadata, and filters to standard chromosomes. HECA reads the supplied ATAC-all.h5ad. Fetal reads supplied Seurat objects and concatenates their counts and aligned metadata. Do not claim an additional uniform cell-QC procedure or donor filtering unless separately documented from the original atlas sources.

Each script uses Signac FindTopFeatures with a quantile cutoff intended to retain up to 100,000 accessible peaks. Set P_target=min(100000,P_input) and q=100(1-P_target/P_input), use min.cutoff='q{q}', then truncate selected VariableFeatures to P_target if necessary. This is an accessibility-based feature selection procedure, not a newly fitted differential-peak filter; cutoff ties/order can matter. Use the recorded final P rather than assume the cutoff always yields exactly P_target. Library size is the sum of retained-peak counts. Preserve raw counts for DA; binarization is applied to the PeakVI input in memory.

Sources: [Kidney](../scripts/01_1_preprocessing_kidney_atac.R), [HECA](../scripts/01_2_preprocessing_heca_atac.R), [Fetal](../scripts/01_3_preprocessing_fetal_atac.R), [AnnData builder](../scripts/02_2_build_peakvi_anndata.py). Dataset accessions, download provenance, donor counts and original biological QC must be supplied from atlas documentation; this specification does not invent them.

## 3. PeakVI representation

Use PeakVI as an established probabilistic representation model, not a newly proposed component. At the model level, z_i has an isotropic Gaussian prior and an encoder approximates its posterior. Binary peak detection is modeled by a Bernoulli probability that combines decoder accessibility with cell- and region-specific factors. A schematic established-model formulation is

    z_i ~ Normal(0,I_d),                 d=60
    b_ip | z_i ~ Bernoulli(pi_ip)
    pi_ip = ell_i * r_p * rho_theta,p(z_i)

The standard variational objective is the sum of evidence lower bounds:

    L = SUM_i { E_q_phi(z_i|b_i)[log p_theta(b_i|z_i)]
                - KL(q_phi(z_i|b_i) || Normal(0,I_d)) }.

This is background for the imported PeakVI implementation, not a reimplementation or a newly derived likelihood. Other library defaults remain those of the recorded production environment. Cite the PeakVI paper and the appropriate version of scvi-tools.

The wrapper specifies normal latent distribution, 60 dimensions, hidden width 256, two encoder and two decoder layers, dropout 0.1, seed 123, and no batch_key in the production rule. The rule uses batch size 2048, GPU and early_stopping=False. The base epoch count is obtained from the installed scvi-tools heuristic (cap=400, decay_at_n_obs=20000); the wrapper fallback is

    t(N) = max(1, min(round(400*20000/N),400)),
    T(N) = 2*t(N).

Use actual heuristic_epochs/max_epochs in each saved peakvi_run_summary.json for the production run, rather than infer an exact epoch count solely from this fallback. The saved Z matrix is returned by model.get_latent_representation(), cast to float32; its installed default posterior-summary behavior should be reported from the production scvi-tools version. No additional scaling/standardization is applied before landmark fitting.

Sources: [training wrapper](../scripts/02_3_run_peakvi.py), [rule parameters](../workflow/Snakefile), results/peakvi/{atlas}/peakvi_run_summary.json. Theory: [PeakVI paper](https://doi.org/10.1016/j.crmeth.2022.100182), [model documentation](https://docs.scvi-tools.org/en/1.2.2/user_guide/models/peakvi.html). This older documentation URL describes model background; it does not establish the installed production version.

## 4. Annotation-blind landmarks

Let z_i in R^60 be row i of Z. MiniBatch K-means approximates the centroid-fitting objective

    minimize over mu_1,...,mu_M: SUM_i min_j ||z_i-mu_j||_2^2,
    M=1024.

This is the objective of K-means, not a claim that the minibatch algorithm finds its global minimum. Landmarks are centroids, not necessarily observed cells or annotation-specific prototypes. The model is fitted to all cells without cell-type stratification.

Implementation: k-means++ initialization; batch_size=8192; max_iter=100; n_init=3; tol=0; max_no_improvement=20; reassignment_ratio=0.01; random_state=123. init_size=max(3*8192,3*1024)=24576. Fit inputs and saved centroids use float32.

Source: [landmark construction](../scripts/03_subset_selection_on_peakvi.py), results/peakvi_landmark_features/{atlas}/peakvi_landmark_metadata.json.

## 5. RBF landmark features and bandwidth

Define nearest-landmark distances and one atlas-specific bandwidth:

    d_i = min_j ||z_i-mu_j||_2,
    sigma = median_i d_i.

Require finite positive sigma. Define the N-by-M affinity matrix

    R_ij = exp[-||z_i-mu_j||_2^2/(2*sigma^2)].

The implementation uses chunked squared distances, clips negative roundoff in squared distances, and writes float32 RBF affinities to a memory-mapped array. The construction chunk size is 50,000 cells. No minimum shift, TF-IDF weighting, density multiplier or cell-type weighting is applied to this matrix in production. It is a rectangular cell-to-landmark feature map, not a pairwise cell-cell matrix or a claimed exact kernel factorization.

Source: [feature construction and sigma definition](../scripts/03_subset_selection_on_peakvi.py), saved sigma TSV and landmark metadata.

## 6. Row-wise L1 normalization

Let a_i=SUM_j R_ij and c=median_i a_i. Validate every a_i>0 and finite. Set

    X_ij = c R_ij/a_i,             SUM_j X_ij=c.

Thus 'L1 normalized' means equal total feature mass, scaled to the atlas median raw row mass. It does not mean rows sum to one. Defining p_ij=R_ij/a_i gives X_ij=c p_ij.

Normalization removes variation in total raw RBF similarity, while preserving each row's relative landmark profile. It can strongly amplify cells with low raw mass; it is not an explicit inverse-density estimator and does not prove rarity recognition. Current production contains no density cap, singleton cap or abundance weight. Historical ablations involving such variants remain separate.

## 7. Submodular objective and marginal gains

Select a cell subset S, not a subset of landmarks. With M fixed and all feature weights equal to one:

    maximize F(S)=SUM_{j=1}^M sqrt(W_j(S)),
    W_j(S)=SUM_{i in S} X_ij,
    subject to S subset of V and |S|=k_f.

For an unselected cell i, its marginal gain is

    Delta(i|S)=SUM_j [sqrt(W_j(S)+X_ij)-sqrt(W_j(S))].

Equivalent stable algebra, where the denominator is positive, is

    Delta(i|S)=SUM_j X_ij/[sqrt(W_j(S)+X_ij)+sqrt(W_j(S))].

A term with both W_j and X_ij zero contributes zero. Since X is nonnegative, F(empty)=0 and F is monotone. If A subset B, then W_j(A)<=W_j(B), and concavity of sqrt implies Delta(i|A)>=Delta(i|B). Summing this inequality establishes submodularity: diminishing returns for additional mass in already-covered landmark dimensions.

Two mathematical consequences help interpretation; they are deductions, not additional measurements:

(a) Scaling every row by the same positive c multiplies F and all marginal gains by sqrt(c). Ideal exact-arithmetic greedy rankings are therefore unchanged relative to row-sum-one normalization. Floating-point/tie/implementation details can still affect actual rankings.

(b) For |S|=k, SUM_j W_j(S)=kc and Jensen/Cauchy-Schwarz gives F(S)<=sqrt(Mkc), with equality for equal landmark totals. The objective rewards spreading accumulated mass across features; it does not require equal annotated-type proportions. At the first selection, Delta(i|empty)=sqrt(c)*SUM_j sqrt(p_ij), so diffuse normalized profiles can receive larger initial gains. This does not establish a universal mechanism of rare-population enrichment.

Source: [normalization and Apricot call](../scripts/03_subset_selection_on_peakvi.py). This objective is concave-over-modular feature coverage; do not relabel it as facility location, k-center, k-medoids, maximum-minimum distance, optimal transport, a DPP or nearest-neighbor coverage minimization.

## 8. Actual optimizer and appropriate theoretical guarantee

The code calls FeatureBasedSelection(k,'sqrt',random_state=123,verbose=True) without overriding optimizer. Saved production summaries record selection_optimizer='two-stage'. The inspected installed Apricot source defaults to two-stage greedy: naive greedy for the first min(10,k) choices and lazy greedy afterward. This is not stochastic greedy, random preselection or a custom optimizer.

The ideal greedy update is

    i_t in argmax_{i not in S_t} Delta(i|S_t),
    S_(t+1)=S_t union {i_t},    S_0=empty.

Lazy greedy uses submodularity to reuse upper bounds and avoid some unnecessary gain evaluations. Under exact greedy selection for a normalized monotone submodular function and cardinality k, the classical bound is

    F(S_greedy) >= [1-(1-1/k)^k] F(S_opt) >= (1-1/e) F(S_opt).

This is a theoretical objective-value guarantee under those assumptions, not a numerical certificate for float32 execution, a guarantee of globally optimal memberships, or a guarantee of any biological evaluation outcome. Cite the classical theorem and Apricot separately; do not claim a new approximation theorem.

Sources: saved results/subset_selection/peakvi/{atlas}/subset_selection_summary_peakvi_{fraction}.tsv; installed apricot/functions/featureBased.py and optimizers.py in myenv; [Apricot API](https://apricot-select.readthedocs.io/en/latest/functions/featureBased.html), [Apricot paper](https://www.jmlr.org/papers/v21/19-467.html), [Nemhauser et al., 1978](https://thibaut.horel.org/submodularity/papers/nemhauser1978.pdf).

## 9. Computational implications

Storing dense float32 R requires 4NM bytes; selection additionally allocates a normalized float32 matrix of the same shape, plus row sums/scales, latent vectors and optimizer overhead. Memory mapping the raw matrix does not make normalized selection fully out-of-core. RBF construction costs O(NMd) arithmetic for d-dimensional distances, plus O(NM) exponentiation/normalization. K-means cost depends on minibatch updates and convergence; max_iter alone does not establish actual runtime.

A straightforward exact greedy implementation has worst-case O(kNM) marginal-evaluation arithmetic. Lazy evaluation can reduce work in practice, but does not justify a universal linear-runtime or memory claim. Report measured Apricot fit seconds separately from full selection-job wall time/RSS and all upstream conversion, training and feature construction. S5 timings are single successful production runs, not controlled replicated scaling experiments. GPU memory, earlier biological preprocessing and failed-run expenditure are not fully measured.

Sources: [selection implementation](../scripts/03_subset_selection_on_peakvi.py), publication_figures/tables/S5_selection.tsv and S5_stage_costs.tsv, logs/benchmarking/.

## 10. Population representation and composition

For each annotated type t, let n_t=SUM_i 1[y_i=t], m_t(S)=SUM_{i in S}1[y_i=t], p_t=n_t/N, and q_t=m_t/k.

    Retained types = SUM_t 1[m_t>0].
    Retention fraction = (retained types)/(number of full-atlas annotated types).
    Enrichment_t = q_t/p_t.
    Log enrichment_t = log2(q_t/p_t), if positive.
    TV(p,q) = (1/2) SUM_t |p_t-q_t|.
    u_t = (p_t+q_t)/2.
    JS_bits(p,q) = (1/2)SUM_t p_t log2(p_t/u_t)
                  +(1/2)SUM_t q_t log2(q_t/u_t).

Use the conventional zero contribution when a summand has zero mass. JS_bits is divergence, not sqrt(JS) distance. Lower TV/JS means better composition fidelity, not necessarily better rare-population utility. Enrichment uses proportions, not the selected count divided by the full-type count alone. A zero selected count gives enrichment zero and log enrichment minus infinity; do not silently introduce an unreported pseudocount.

DA eligibility is a separate binary quantity:

    E_t(S)=1[m_t>=10 AND k-m_t>=20].

Population presence, eligibility and statistically significant recovery are distinct outcomes. Sources: scripts/06_1_compute_cell_type_proportions.R; publication_figures/scripts/common.py; tables/S2_*.tsv.

## 11. Uniform-random baseline and analytical retention probabilities

The implemented baseline draws exactly k cells uniformly without replacement. Seeds are 2001,...,2020. RNG streams use NumPy default_rng(SeedSequence([seed,atlas_index,pct])), with atlas order Kidney=0, HECA=1, Fetal=2 and pct in {2,4,6,8,10}. Budgets are not nested. Stored membership hashes and count vectors permit provenance checks. No matched-budget stratified baseline or external sketching-method comparison should be claimed unless separately supplied.

For mathematical interpretation, under uniform random sampling alone,

    M_t ~ Hypergeometric(N,n_t,k),
    Pr(M_t=x)=choose(n_t,x)*choose(N-n_t,k-x)/choose(N,k),
    E[M_t]=k*n_t/N,
    Var(M_t)=k*p_t*(1-p_t)*(N-k)/(N-1).

Consequently Pr(type present)=1-choose(N-n_t,k)/choose(N,k), and

    Pr(DA eligible)=SUM_{x=max(10,0)}^{min(n_t,k-20)} Pr(M_t=x),

with infeasible terms interpreted as zero. Expected retained-type count is the sum of individual presence probabilities; type counts are not independent. These are analytical identities, not newly calculated numerical benchmark findings. They explain why complete retention at a small percentage may be unsurprising when N is large and the smallest populations are sufficiently abundant.

The actual figures use saved empirical counts: eligibility frequency=(1/20)SUM_s E_t(S_s), and empirical 2.5th/97.5th seed percentiles where shaded. These percentiles are not confidence intervals, biological replicates or estimates of 20-seed DA performance.

Sources: publication_figures/scripts/deferred_benchmarks.py; benchmarks/full/*_provenance.json and *_populations.tsv; reports/scientific_followup/REPORT.md.

## 12. DA testing and exact count-based effect definition

For a cell collection D (full atlas or selected subset) and type t, define G_t={i in D:y_i=t} and H_t=D minus G_t, of sizes n_G,n_H. Test only types with n_G>=10 and n_H>=20. Use retained original counts C, not PeakVI latents or binarized model input.

BPCells marker_features(method='wilcoxon') tests target versus rest for each peak. A rank-sum test is based on pairwise order comparisons, schematically U=SUM_{i in G}SUM_{h in H}(1[C_ip>C_hp]+0.5*1[C_ip=C_hp]). Production p-values, tie handling and asymptotic/exact choices are those of the installed BPCells implementation; do not invent an implementation variant from this schematic statistic. The code invokes marker_features separately on C>0 to obtain detection fractions.

Let mu_G,p and mu_H,p be mean original counts. The implemented effect is exactly

    L_tp(D)=log2[(n_G*mu_G,p+1)/n_G]
            -log2[(n_H*mu_H,p+1)/n_H]
           =log2(mu_G,p+1/n_G)-log2(mu_H,p+1/n_H).

This is NOT log2(mu_G,p+1)-log2(mu_H,p+1). The pseudocount depends on group size; changing subset sizes/rest composition can alter effects even beyond testing power. Detection fractions are rounded to six decimals before threshold comparison.

Within each eligible type, apply BH to the tested matrix-peak p-values before detection filtering. For sorted p_(r), BH adjusted values have the standard monotone form min(1,min_{s>=r} P*p_(s)/s), using the actual valid test universe/library NA behavior. Retain a significant peak if

    adjusted_p<=0.05,
    |L_tp|>=0.25,
    max(detection_G,p,detection_H,p)>=0.01,

with finite required values. 'Open' means L>0 and 'closed' L<0 relative to the rest, not absolute accessibility/closed chromatin. BPCells Wilcoxon through Seurat/Signac objects is not PeakVI's Bayesian differential-accessibility procedure. No donor-level pseudobulk model, donor random effect or explicit covariate-adjusted DA model should be asserted for this implementation.

Source: [production DA script](../scripts/09_1_run_signac_da_all_cell_types.R). Related full/subset status tables record eligibility and computational outcomes separately.

## 13. Reference universes and fidelity denominators

Let R_t be type t's significant full-atlas reference peaks, and R={(t,p):p in R_t}. Freeze full-atlas significance and direction before subset comparisons. Let A(D) subset R contain pairs with finite available subset effects. Missing effects can arise because types are ineligible or because of computational/input problems; keep status records to distinguish these.

For pair a=(t,p), write u_a=L_tp(full), v_a=L_tp(D). Define

    same_a=1[u_a*v_a>0], switched_a=1[u_a*v_a<0],
    strict_a=1[v_a is subset significant AND u_a*v_a>0].

Then

    availability = |A|/|R|,
    direction agreement = SUM_{a in A} same_a / |A|,
    sign-switch fraction = SUM_{a in A} switched_a / |A|,
    strict recovery = SUM_{a in R} strict_a / |R|.

Zero effects are in neither sign numerator, so agreement+switch fraction can be less than one. Strict recovery uses the full reference denominator even if some types have no available subset effects. Availability therefore changes the interpretation of recovery. For ineligible populations the count-based strict statistic can be zero, but an evaluation plot should distinguish this from an eligible measured zero; main Figure 1 uses a DA-ineligible display label rather than a zero bar.

Spearman rho is Pearson correlation of average-tie ranks of u and v over the specified available pairs. Pearson uses the unmodified effects directly. Safe correlations are NA with fewer than three finite pairs or zero variation in either variable. Median absolute error is median_{a in A}|u_a-v_a|. Pooled correlations concatenate peak-type pairs; they are not averages of per-type correlations and weight types with more reference peaks more heavily. Per-type, direction-specific and explicitly macro-averaged values answer different questions.

Changing sign-switch denominators across budgets follows from changing |A(D)|, even when R is fixed. Do not call these denominators arbitrary or compare numerator counts without availability. Separate open/closed analyses restrict R/A using the FULL reference sign, not a subset-dependent reclassification.

Source: [capture summaries](../scripts/09_2_compute_signac_da_peak_capture.R), scripts/10_2_plot_publication_signac_da_panel.py; tables/S3_*.tsv; reports/random_DA_stage_A_2001/definition_QA.tsv.

## 15. Latent-space coverage: measurement, approximation and limits

For selected positions S in raw saved 60D space, define the ideal distance

    d_i(S)=min_{j in S}||z_i-z_j||_2.

Report mean/median and 90th/99th percentiles over the declared query cells, and

    Coverage_r(S)=(1/|Q|) SUM_{i in Q}1[d_i(S)<=r].

All-query Q=V includes selected cells at zero. Nonselected-query Q=V minus S is also saved; its query identities differ between methods. These are cell-weighted measures, distinct from annotation retention or the optimized RBF objective.

Actual distances are approximate nearest-neighbor estimates: PyNNDescent Euclidean indices, 30 graph neighbors, index seed 1705, one thread in saved production benchmark; returned candidate distances are recomputed in float64. Candidate minima are upper bounds on ideal nearest distances, apart from numerical effects. Adaptive epsilon is validated on up to 128 exact queries, requiring >=99% within 1% relative tolerance plus absolute 1e-7. This allows an occasional large miss and does not guarantee every tail quantile or radius indicator.

Each atlas has one fixed r, calibrated as the 90th percentile of estimated full-atlas nonself-nearest distances for 50,000 fixed sampled queries (query seed 1703, index seed 1701), then reused for all budgets/methods. Conditional on fixed r, candidate-distance coverage is conservative relative to exact distances; r itself is also ANN-estimated. Distances/radii are not directly comparable in biological units between atlases. Protocol versions/effective search effort and accuracy limitations are recorded in the scientific audit.

Source: publication_figures/scripts/deferred_benchmarks.py; benchmarks/radius/ and full/; reports/scientific_followup/REPORT.md.
