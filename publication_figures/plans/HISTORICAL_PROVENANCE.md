# Historical ablation provenance

Exact original sources are enumerated in tables/SOURCE_MANIFEST.tsv with file hashes. Both `diagnostics/summarize_rbf_normalization_ablation.py` and `diagnostics/summarize_l1_normalization_generalization.py` load a SINGLE --umap_tsv into coordinates before looping over methods. Thus within-run distance summaries compare the same geometry. Original workflow rules specify `results/umap_peakvi/{atlas}/{atlas}_peakvi_umap.tsv` as that input. The September historical summaries predate October regenerated production UMAPs; no archived embedding hash is available to establish byte-identical old/new coordinates. S1 labels these as historical 2D UMAP distances and does not compare distance magnitudes between atlases or infer 60D geometry preservation.

Historical L1 selected-ID lists were compared with production as sets: all 14 available lists match (five budgets Kidney/Fetal, four through 8% HECA). See S1_historical_subset_identity.tsv. This does not prove embedding byte identity or provide independent replication. The historical 'baseline' names unnormalized RBF Apricot selection, NOT uniform random sampling. Its original selected-ID paths were later reused by production L1 selection; the historical tables are preserved observations, but those paths cannot now be used to recreate baseline memberships. No original figure or result was modified.

Singleton-capped means the historical capped singleton-gain transformation, not cell-type stratification. Definitions remain in diagnostics/run_rbf_normalization_ablation.py. No DA or random-baseline advantage is inferred from these method ablations.
